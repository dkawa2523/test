### 新規ガスを化学から絞る


#### 用途と手順

最初の問いは「基板元素を気相へ運び出せるか」である。候補分子の安定性や結合解離だけでなく、吸着、表面改質、基板原子との結合交換、揮発性生成物の形成、脱離、残った表面の再活性化を一巡させる。ALEでは、改質剤と除去剤の組合せを探索単位にする。

| 評価 | 入力と計算 | 出力と採用判断 |
| --- | --- | --- |
| ガスの反応性 | 分子構造、電荷・スピン、DFTまたは高精度分子計算 | 解離、プロトン移動、錯体形成の候補。表面反応性は別評価 |
| 熱力学 | 反応物・表面・気体生成物の自由エネルギー、T、分圧 | 反応の駆動力。有利でも速いとは限らない |
| 揮発化 | 単量体・二量体・付加体・塩の候補、脱離経路 | 除去可能性。生成物が表面に残る経路も比較 |
| 速度と選択性 | 対象膜と保護膜の吸着・TS、被覆率 | 候補温度域、競合反応、残渣や停止層の危険 |
| 供給と循環 | 気相安定性、供給温度、反応器内生成種 | 表面に到達できる候補か。再堆積や壁反応も評価 |

#### メリットと限界

分子計算は、新元素や新しい配位子の組合せにも着手しやすく、経験力場が未整備でも比較できる。分子DFTから少数の表面DFTへ進む段階的な絞り込みは、候補全てに大規模MDを実施するより初期投資を抑えやすい。

ただし、分子の沸点や反応熱だけによる順位付けは不十分である。表面錯体の強い結合、非揮発性の塩、改質層内拡散、気相での会合により、除去が停止する場合がある。実験の蒸気圧や熱分析データが入手できるなら計算と照合する。DFTから蒸気圧を得る場合も、凝縮相との自由エネルギー差を要し、分子1個の計算だけでは済まない。

#### 実装と費用

分子の高精度化にはORCA、周期表面にはCP2K、Quantum ESPRESSO、VASP、探索前処理にはxTBが候補となる。初期比較は小規模から開始できるが、表面被覆、相、TSの組合せが主要な費用を決める。ORCAは学術利用と企業利用の条件が異なり、企業の研究用途を一律に無料と扱わない。[[S01](#s01)–[S05](#s05)]

### DFTと遷移状態計算で反応を決める


#### 用途と原理

周期境界のスラブDFTは、吸着と表面結合切断、フッ化・塩化、配位子交換、基板原子の脱離をエネルギー地形として比較する主力である。分子クラスター計算は反応中心を詳しく扱えるが、切り出し境界、電荷、誘電環境の影響を点検する。

CI-NEBは既知の始状態と終状態を複数の中間像でつなぎ、最小エネルギー経路を探索する。dimer法やSellaなどの鞍点最適化は、終状態が確定しない局所探索にも使える。TSは虚振動とその方向、両側へ緩和した生成物を確認する。NEBの最大エネルギー像をTS候補として精密化し、振動と接続先を確認する。[[S06](#s06)]

| 項目 | 具体的な内容 |
| --- | --- |
| 入力 | 原子構造、終端・被覆、汎関数、擬ポテンシャル、基底・カットオフ、k点、電荷・スピン。NEBには両端構造 |
| 出力 | 吸着・反応エネルギー、TS、障壁、振動、電子状態。補正後の自由エネルギーと速度定数 |
| 長所 | 新規元素組合せに比較的対応しやすい。反応の原因を電子状態と構造で説明できる |
| 短所 | 汎関数誤差、有限サイズ、非晶質サイトのばらつき。反応ネットワークの完全性は保証されない |
| コストと導入 | 中〜高。NEBは複数像と反復が必要。計算器の導入は中程度、信頼できる表面・TS設定には専門性が必要 |

#### エッチングで必要な設定

未反応面だけでなく、低・高被覆、欠陥、共吸着H₂OやNH₃、反応途中の改質層、保護膜も比較する。気相分子の並進・回転エントロピー、表面振動、圧力の化学ポテンシャルを扱い、0 Kの電子エネルギーとプロセス自由エネルギーを区別する。柔らかい吸着モードに機械的な調和振動子近似を使うとエントロピー誤差が大きくなるため、必要に応じて自由エネルギー法へ進む。

HFによるSiO₂対Siの選択エッチングをDFTで調べた2023年の研究は、表面の段階的フッ化と反応障壁を比較した直接的な事例である。特定の結晶・終端モデルの結果を、別の非晶質膜や共反応物条件へ移す際には再計算が必要となる。[[R01](#r01)]

既知の始終状態にはNEB、局所的なTS候補にはdimerまたは鞍点最適化を使う。生成物自体が不明な場合は[未知の反応経路を探索する](#section-8)の探索へ戻る。NEB像数を増やすことだけでは未登録の分岐は解決しない。

### AIMDと近似量子MDで反応を観察する


#### 第一原理分子動力学

AIMDは各時刻の力を電子状態計算から求める。反応イベントの一覧を先に与える必要がなく、プロトン移動、協奏反応、局所的な配位変化、非晶質化の観察に向く。CP2K、VASP、Quantum ESPRESSOなどが候補となる。[[S01](#s01)–[S03](#s03)]

入力はDFTの条件に加えて温度、初期速度、時間刻み、境界・拘束、熱浴である。出力は軌跡、構造分布、力、観測された反応である。利点は未知の局所反応を電子状態に基づいて調べられる点で、欠点は1ステップの費用が大きく、稀な反応が起きるまで待てない点である。短い軌跡で未観測の反応は、障壁と観測時間から発生頻度を評価する。

#### DFTBおよびxTBによる近似量子計算

DFTBは電子状態計算をパラメータ化した近似で、xTBは広い化学空間を狙う半経験的タイトバインディング法である。構造生成、会合体、反応経路候補、AIMDより長い探索に有用だが、反応障壁や表面電荷移動はDFTで再評価する。DFTBでは元素ペアを含む適切なパラメータ一式が特に重要で、別々のパラメータ集合を無検証に混ぜない。[[S05](#s05),[S07](#s07)]

| 方法 | 入力と出力 | 採用範囲と計算費用 |
| --- | --- | --- |
| AIMD | 電子状態の設定と初期構造 → 軌跡、反応候補、有限温度構造 | nm局所領域・短時間を重点化。費用は非常に高い |
| DFTB MD | Slater–Koster等のパラメータと構造 → 軌跡、反応候補 | パラメータが対象結合に適合する場合。費用は中〜高 |
| xTB探索 | 分子・クラスター、電荷・スピン → 構造、経路候補 | 候補を多く作りDFTで選別。周期表面の対応は実装ごとに確認 |

#### 有効な使い分け

初期の未知反応探索には、小さな反応中心でAIMDや探索法を使う。非晶質モデルを作ったら密度、局所配位、表面組成を検証し、複数の独立構造で再現性を調べる。高温や過剰なガス投入で見つけた反応は仮説として保存し、実温度の障壁と競合経路を別途求める。

AIMDを使って非晶質Al₂O₃とAlF₃のモデルを作り、HFとTMAによる反応をDFTで解析した2025年の原著は、構造生成と機構計算を分担した例である。全プロセスを直接AIMDで時間追跡したものと解釈しない。[[R05](#r05)]

#### MDエンジンの入力と力計算器の選定

構成図A03の中心は、座標から力を計算し、その力で座標・速度を更新する反復である。AIMD、反応力場MD、MLIP-MDはこの反復を共有し、力計算器が異なる。温度制御と境界条件は別の入力として扱う。


<a id="fig-a03"></a>

![構成図A03：MDエンジンと力計算器の分離](figures/A03.png)

**構成図A03　MDエンジンと力計算器の分離。** 原子種・座標・セルと初期速度を入力し、力評価と時間積分を反復して軌跡を得る。電子状態計算・古典力場・MLIPは代替の計算器であり、無条件に同時使用する構成ではない。


出力軌跡からは、結合・配位数の変化だけでなく、脱離物の組成、表面内に残る基板結合、被覆状態を解析する。判定規則を固定しないまま動画を見て反応数を数える運用は、比較結果が担当者に依存する。反応検出器は原子種、結合判定の閾値、持続時間、表面からの距離を記録可能な処理として実装する。

電子状態が未知で少数経路の理解を優先するならAIMD、検証済みパラメータがあり多数の構造候補が必要ならDFTB/xTB、同一化学系の多数衝突なら反応力場または専用MLIPを選ぶ。DFTB/xTBは予備探索と位置付け、採否を左右する障壁を統一したDFTで再評価する。[[S01](#s01)–[S03](#s03),[S05](#s05),[S07](#s07)]

### 反応性古典MDで多数の衝突を扱う


#### ReaxFFと結合次数型ポテンシャル

ReaxFFやTersoff・REBO系の反応対応ポテンシャルは、原子配置から結合状態と力を計算する。反応リストを与えずに結合の生成・切断を扱えるが、利用可能な反応はパラメータの再現範囲に制約される。通常の固定結合型分子力場は、未知のエッチング化学の主計算器には適さない。

| 項目 | 具体的な内容 |
| --- | --- |
| 入力 | 対象元素を同時に扱う検証済み力場、表面、入射種・速度・角度、温度、境界、熱浴、電荷平衡条件 |
| 出力 | 入射ごとの反応・反射・付着・除去確率、生成物、損傷、被覆、改質深さ、原子軌跡 |
| 長所 | DFTより多数の原子と衝突を扱いやすい。反応確率や表面変化の統計を集めやすい |
| 短所 | 採用前に対象反応の障壁をDFTと比較する。電荷平衡、短距離反発、熱除去の扱いに依存 |
| コストと実装 | 1軌跡は低〜中、統計全体は大きくなる。LAMMPSは無償、AMSのReaxFF環境は有償。新規パラメータ開発は重い |

#### ケミカルエッチングへの適用条件

HFとSiO₂を扱うReaxFF研究では、対象反応に合わせた量子化学データとパラメータ化が用いられた。これは「汎用ReaxFFを読み込めば任意の新規ガスを評価できる」という根拠にはならない。また、入射エネルギーを与えたMDの除去収率を、そのまま低温熱反応の速度に置き換えない。[[R03](#r03),[S08](#s08),[S09](#s09)]

実験と比較する場合は、試料の表面組成、入射エネルギー分布、フラックス比、損傷層を揃える。入射イベント間の緩和時間を短縮すると、熱蓄積や被覆変化を誤って増幅し得る。基板底層の拘束と熱浴の距離を変え、エネルギー散逸が反応を支配していないか確認する。

#### 力場を採用する前の短い検証

ガス分子と主要生成物の安定性、解離曲線、代表吸着、少数の律速候補障壁、清浄面と改質面の構造をDFTと比較する。全てを同時に再現できなければ、利用範囲を衝突・構造解析に限定するか、専用パラメータまたは第2部のMLIPへ進む。力場を別のガス用に単純に転用する判断は避ける。

#### 解像度と反応の記述範囲

概念図03は、全原子反応性MD、局所を量子化するQM/MM、多数原子をまとめる粗視化を比較する。計算対象を大きくする際は、削減する自由度が目的の結合切断・拡散・損傷に関与していないかを判断する。


<a id="fig-c03"></a>

![概念図03：反応性MD・QM/MM・粗視化の解像度](figures/C03.png)

**概念図03　反応性MD・QM/MM・粗視化の解像度。** 全原子、局所量子領域、粗視化ビーズという異なる解像度を示す。粗視化のビーズ間結合を、実原子の共有結合反応と直接対応させない。


**採用判断。** LAMMPS＋ReaxFFは、対象の元素組合せだけでなくガス・表面・生成物・律速候補を同時に再現するパラメータがある場合に選ぶ。GUIによる解析や商用サポートを重視する場合はAMSを比較する。どちらも新規ガスのパラメータ適合性を別途検証する。[[S08](#s08),[S09](#s09)]

開発判断には、代表的な吸着・解離・脱離のDFT比較表を用いる。特定の障壁だけが外れるモデルを、温度を調整して実験速度へ無理に合わせない。統計が大量に必要で、既存力場の修正が広範囲に及ぶ場合には、[専用MLIPを作る場合の選択](#section-19)の専用MLIPと開発費を比較する。

### 未知の反応経路を探索する


#### AFIRとGRRM

AFIRは原子・フラグメント間に人工的な力を加え、反応経路を探索する。入力は初期構造、反応させる領域、探索条件、エネルギー・勾配計算器であり、全ての生成物やkMCイベントを先に列挙する必要はない。出力は中間体、反応候補、接続ネットワークで、最終TSや障壁は再最適化する。[[S10](#s10)]

新規ガスの会合、分解、配位子交換、局所的な表面反応に有用である。一方、大きな非晶質表面全体を無制限に探索すると組合せが増大する。反応領域と固定原子、気体分子数、エネルギー範囲を限定し、複数の初期配置で探索漏れを評価する。探索の終了は、反応ネットワークの完全性の証明ではない。

#### Pyntaによる表面反応計算の自動化

Pyntaは表面吸着構造、TS、熱化学・速度係数の計算を自動化するワークフローである。主に金属表面で開発されており、ユーザーが与える反応の定義と原子対応、表面サイト情報を用いる。未知の全てのエッチング反応を自動発見する汎用エンジンとして扱わない。酸化物、非晶質、厚い改質層には適用可否の検証や拡張が必要となる。[[R06](#r06),[S11](#s11)]

| 方法 | 何を事前に与えるか | 適した用途と制約 |
| --- | --- | --- |
| CI-NEB | 始状態と終状態 | 既知候補経路の障壁。未知生成物の発見は別手段 |
| dimer・鞍点探索 | 初期構造と探索方向など | 近傍のTS。どの反応へ行くかの制御と同定が必要 |
| AFIR | 初期構造、探索範囲、計算器 | 未知反応候補。探索費用と反応領域の設計が課題 |
| Pynta | 反応定義、表面と吸着種、計算器 | 多数の構造・TSの自動計算。適用表面の検証が必要 |

#### 導入と開発判断

ASEのNEBは既存計算器に接続しやすい。GRRMは有償で、計算器側の費用も別途必要となる。Pynta本体はGPLv3で公開されるが、DFT実行系、FireWorks、計算資源管理を含む環境構築が必要である。2026年7月公開のGRRM26は、高速な半経験的法やMLポテンシャルを使う場合の性能改善を公式に案内している。[[S06](#s06),[S10](#s10),[S11](#s11)]

### 自由エネルギー計算で遅い反応を探る


#### MetadynamicsとOPES

吸着分子の解離、プロトン移動、表面原子の脱離などを表すCVに沿ってバイアスを加え、通常MDでは訪れにくい状態を探索する。OPESは観測された分布から目標分布へ近づくバイアスを構築する。いずれもDFT、反応力場、MLIPなどの計算器を必要とし、手法自体が機械学習モデルというわけではない。[[S12](#s12)]

| 方法 | 入力から出力へ | 採用条件と弱点 |
| --- | --- | --- |
| Umbrella sampling | 反応座標と窓ごとの拘束 → 平均力ポテンシャル | 経路の見当がつく場合。窓間重なりと遅い直交自由度が重要 |
| Well tempered metadynamics | CVとバイアス条件 → 経路候補と自由エネルギー差 | 複数準安定状態の探索。CVから漏れた障壁に弱い |
| OPES・OPES explore | CVと目標分布など → 状態探索・自由エネルギー | 効率的な探索候補。再重み付け可能性と収束を確認 |
| Infrequent系・flooding | 状態、CV、バイアス制約 → 脱出時間や速度推定 | TS付近へのバイアス影響等の前提が必要。実時間の評価には手法固有の時間補正と適用条件の確認が必要 |

#### エッチングに必要なCV

Si–FやM–配位子の配位数、基板原子の高さ、Hの移動、残存基板結合数などを候補にする。ただし、高さだけでは基板から切れていない錯体を脱離と誤判定し得る。複数の結合と周辺被覆を組み合わせ、独立軌跡で経路が変わらないか調べる。

自由エネルギー面は、指定した温度、組成、粒子数、CVの条件付き結果である。固定粒子数の小セルで得た結果を、分圧が変わる開放系へ渡す際には、気体化学ポテンシャルと吸脱着の扱いを整合させる。

#### コストと実装

PLUMEDとCP2KまたはLAMMPSの連携が代表的である。費用は基礎MDの長さ、CV計算、窓や独立試行数で決まり、単発MDより軽いとは限らない。PLUMEDのPythonパッケージを入れるだけで、任意のMD実行系に機能が追加されるわけではない。連携対応、リンクまたはパッチ、ビルド構成を確認する。[[S12](#s12)]

### 物理的な速度と長時間を得る


#### 遷移状態理論から速度定数を作る

平衡化された準安定状態と明確な障壁がある場合、遷移状態理論では k(T) ≈ κ(kBT/h) exp[−ΔG‡/(kBT)] と表せる。κは再交差などを補正する透過係数である。吸着の気相標準状態、表面サイト密度、被覆率、逆反応との整合性を揃えて速度論モデルへ渡す。

| 手法 | 追加入力と出力 | 主な条件と費用 |
| --- | --- | --- |
| Hyperdynamics | 状態内バイアス → 補正された経過時間 | 境界付近のバイアス条件が重要。加速率は系に依存 |
| Parallel replica dynamics | 準安定状態と独立レプリカ → 状態脱出時間 | 状態内平衡化と脱出統計の仮定。多数のCPU/GPUを消費 |
| Temperature accelerated dynamics | 高温軌跡と障壁評価 → 低温イベント推定 | 調和TSTなどの条件。高温で新しい機構が支配すると難しい |
| Weighted ensemble | 進行度、ビン、状態定義、重み → 反応流束・初到達統計 | 軌跡の分割・統合で稀な経路を強化。定常化と相関誤差を評価 |

LAMMPSにはhyper、prd、tadの公式実装がある。WESTPAはweighted ensembleの実装基盤で、外部の軌跡計算器と連携できる。これらは事前登録したkMCイベント一覧を必須にしないが、状態定義や適用仮定をなくす方法ではない。[[S13](#s13),[S14](#s14)]

#### 開放系の表面に適用する際の判断

ガスが継続的に到達し、被覆や表面形状が急速に変わる系では、定常的な準安定状態という前提が崩れやすい。まず一定被覆や単一脱離過程など限定した問題に適用し、到達イベントは別の確率過程として結合する。全エッチングを一括して「加速MDで秒まで延長できる」とは見積もらない。

#### 速度の精度をエネルギー精度に結び付ける

同じ前因子を仮定すると、速度の倍率fに対応する障壁差は kBT ln f である。400 Kでは2倍が約0.024 eV、10倍が約0.079 eVとなる。これはDFTやMLIPの一律の合格基準ではなく、速度予測が小さな障壁誤差にも敏感であることを示す。候補間の順位、実験誤差、モデル近似を含めた感度解析で必要精度を決める。

概念図06と構成図A06は、時間補正、独立レプリカ、高温からの外挿、重み付き軌跡という異なる仕組みを分けている。目的が反応発見か、物理的な脱出時間かによって採用条件が変わる。

**概念図06　長時間化と重み付き軌跡。** hyperdynamics、parallel replica、TAD、weighted ensembleの概念比較。レプリカ本数や模式的な加速率は性能保証ではない。

### QM/MMと粗視化などの補助手法


大空間に特化した方法でも、未知の表面化学を表す情報が別途必要になる。以下は用途を限定すれば有効な補助手法である。

| 区分 | 入力と出力 | 利点と採用を止める条件 |
| --- | --- | --- |
| QM/MM・埋込み | QM反応領域、MM周辺、境界・電荷結合 → 局所反応と周辺緩和 | 局所を高精度化。反応が境界を横切る、電荷移動が広域なら難しい |
| 適応QM/MM | 領域更新規則と結合方式 → 移動する反応領域 | 反応場所の移動に対応。エネルギー保存と領域境界の開発負担が大きい |
| 粗視化MD | ビーズ写像と有効相互作用 → 膜・層・集団の構造と緩和 | 空間拡大に有効。未知共有結合化学と時間換算は自明でない |
| 反応性粗視化・DPD | 粗視化相互作用と反応則 → 組成輸送と集団挙動 | 厚い層や輸送に候補。反応定数を入力する構成は機構発見器ではない |
| GCMCとMDの併用 | 温度、化学ポテンシャル、挿入・削除規則 → 平衡吸着量など | 被覆状態の生成に有効。MCステップは平衡状態のサンプリング回数を表す |
| k ART・適応kMC | 局所構造、鞍点探索、率 → 長時間の構造遷移 | イベントを逐次発見。ただし分類上はkMCであり非kMCではない |

#### エッチングでの具体的な使い道

QM/MMでは反応サイトだけを量子化し、厚い基板の弾性応答を古典領域で表す。非晶質膜の局所脱離などが候補だが、導電性や長距離分極が重要な場合は埋込み方式を慎重に選ぶ。CP2KはQM/MMの実装を提供する。[[S15](#s15)]

粗視化では、原子層より厚い改質膜の拡散や多成分層の形態を扱う余地がある。ただし反応中心を残した混合解像度の設計や、反応物・生成物ごとの輸送係数が必要である。一般的なDPDを導入しても、新規ガスによるSi–O切断機構は得られない。LAMMPSの反応対応粗視化機能にも、反応モデル側の入力が必要となる。[[S16](#s16)]

k-ARTは局所環境に応じてイベントを探索する方法で、事前イベント表を減らせる点が有用である。しかし、不完全なポテンシャルの誤りを修復するものではなく、入射ガスと動く表面への組込みには開発が必要である。[[R15](#r15)]

#### 周辺環境・有効自由度・吸着平衡を区別する

構成図A08の三つの枝は、別々の問題を解く。QM/MMは反応中心と周囲の結合、粗視化は削減した自由度の有効相互作用、GCMCは粒子数を変化させる平衡サンプリングを必要とする。

![構成図A08：QM/MM・粗視化・GCMCの入出力](figures/A08.png)

### 表面速度論：MKMとkMCを選ぶ


#### 平均場MKMと反応拡散

MKMは吸着種の被覆率や中間体量の時間変化を、素反応の速度式とサイト収支で解く。必要な入力は反応ネットワーク、温度依存速度、分圧・フラックス、サイト密度、初期被覆である。出力は速度、被覆、誘導時間、生成物フラックス、感度であり、kMCイベントを時系列に抽選する必要はない。Canteraなどが実装候補となる。[[S17](#s17)]

MKMも反応ネットワークは必要である。「kMCの入力を使わない」とは「反応情報が不要」という意味ではない。DFTやMDから速度を計算するか、実験から同定する。局所の島形成、隣接種の協奏反応、サイト間の強い相関を平均化すると誤差が出る。必要なら対相関、複数サイト、空間分割を追加し、さらに必要な場合にkMCへ進む。

| 区分 | 得意な出力 | 採用基準 |
| --- | --- | --- |
| 平均場MKM | 速度、被覆、EPC、パラメータ感度 | 表面が概ね混合され、局所相関を詳細に追わなくてよい |
| 空間分解反応拡散 | 位置別の濃度・被覆、改質層の拡散律速 | 拡散係数・反応速度・境界条件が与えられる |
| 格子kMC | サイト配列、島、局所反応、揺らぎ | 隣接関係や確率分布が結果に重要 |
| 非格子・自己学習kMC | 格子が崩れる表面の長時間変化 | イベント探索と障壁計算の費用を許容できる |

#### 気体の到達と表面反応をつなぐ

平衡Maxwell分布の理想気体なら、単位面積への入射フラックスは Jᵢ = Pᵢ/√(2πmᵢkBTg) と書ける。付着係数と空きサイト割合を掛け、サイト密度で換算して被覆変化率を得る。分子ビーム、方向性の強い流れ、非平衡プラズマ種では、この式の代わりに実際の分布または輸送計算結果を用いる。

同一条件の独立な入射試行では、反応確率の推定値は成功回数/試行回数となる。反応ゼロでも確率ゼロとは言えず、独立同分布を仮定した95%上限の概算は3/Nである。表面が各衝突で変化する連続照射は独立同分布ではないため、被覆・履歴で条件分けして統計化する。

#### 同じ反応機構から二つの速度論を選ぶ

概念図07は、平均被覆率で状態を表すMKMと、サイトごとの配置を保持するkMCの違いを示す。構成図A07の共通入力は、検証した素反応と速度則である。

### 輸送と形状で実用スケールを扱う


#### 表面モデルに加えて必要な物理

µmの溝形状やウエハ内分布を知りたい場合、表面の反応機構だけでは不足する。ガスが底へ届くか、側壁に失われるか、生成物が再衝突するかを計算する。モデル選択はKnudsen数Kn = 平均自由行程/代表長さを目安にし、実際の衝突・境界条件に合わせる。

| 方法 | 入力から出力へ | 適した条件と弱点 |
| --- | --- | --- |
| 粒子・ray Monte Carlo | 形状、入射分布、付着・反射・反応確率 → 局所フラックス | 分子流に近いフィーチャー。分子間衝突を省く場合は適用条件を確認 |
| DSMC | 分子衝突モデル、境界、気相反応 → 希薄気体分布・到達量 | 希薄流れ。セル・時間刻み・模擬粒子数の収束が必要 |
| CFDと反応輸送 | 流量、物性、反応機構、壁条件 → 分圧・温度・濃度場 | 連続体が妥当な反応器。低圧・細孔でそのまま使えない場合がある |
| Level set・表面追跡 | 局所の法線方向除去速度 → 形状変化・深さ・均一性 | nm〜µm形状。検証済みの局所反応則を入力する |

#### 実装候補と費用

ViennaPSはフィーチャーの輸送と表面形状を扱う公開基盤である。SPARTAは希薄気体のDSMCに使える。Canteraは気相・表面反応と熱化学の構成要素を提供するが、任意の3次元反応器・移動境界問題を単独で自動生成するわけではない。輸送ソルバーとの連携や境界条件の実装が必要となる。[[S17](#s17)–[S19](#s19)]

原子計算に比べて長時間・大空間を扱いやすい一方、入射粒子数、メッシュ、表面状態数、サイクル数で費用は増える。表面反応則を過度に単純化したままメッシュだけ細かくしても、予測精度は改善しない。

#### 最近の直接的なエッチング例

2026年のALD/ALE国際会議では、HF/NH₃によるSiO₂のCOR型ALEを、ViennaPSのray tracingとlevel setで扱う発表がある。改質塩層の形成と層内輸送、HFによる直接除去を組み合わせ、平面データで校正して溝へ適用している。これは実装方針の参考になるが、確認した資料は会議要旨であり、査読論文や汎用コード公開の確認とは分ける。[[R10](#r10)]

### 用途例 HF系でSiO2とSiNxを比較する


#### 問うべきこと

HF系の新規添加ガス探索では、反応を速めるかだけでなく、対象膜と保護膜のどちらを促進するか、塩や終端が残るか、パルスと加熱で反応が分離できるかを比較する。乾燥度、OH終端、膜中H、NH₃などの共反応物を明示する。

| 段階 | 推奨計算と入力 | 次段階へ渡す出力 |
| --- | --- | --- |
| 1 反応候補 | 対象・保護膜の複数終端とHF・添加分子のDFT | 吸着、プロトン移動、フッ化、脱離生成物の候補 |
| 2 経路の確認 | NEB・鞍点探索。未知の会合や多分子過程はAFIR・AIMD | 競合障壁、塩形成と直接揮発化の分岐 |
| 3 被覆と改質 | 表面MKM。必要なら検証済み反応MDやMLIP MD | 被覆率、改質層厚さ、時間依存の反応係数 |
| 4 パルスと形状 | 曝露・パージ・加熱の速度論と輸送・形状計算 | EPC、停止条件、深さ依存、残渣リスク |
| 5 検証 | 平面の速度・表面組成・生成物、独立した溝条件 | 候補の選択性とプロセス窓、モデルの適用範囲 |

#### 文献から使える知見と使えない飛躍

SiO₂対SiのHF選択エッチングにはDFTの直接例がある。[[R01](#r01)] HFとSiO₂の反応性MDにも専用ReaxFFの例がある。[[R03](#r03)] さらに2024年には、非晶質Si₃N₄に対するHFエッチングをMLIPで扱い、原子計算から連続体モデルへつないだ研究がある。[[R04](#r04)]

これらを単一の条件のデータとして合算しない。材料の水素含有、表面終端、入射エネルギー、力場の学習範囲が異なる。特に高い入射エネルギーで測った除去収率と、熱的な分子吸着・脱離の速度は異なる量である。

#### 選定判断

少数の新規添加分子を比べる段階はDFTと経路計算を優先する。候補が絞れ、非晶質サイトや被覆の統計を多数必要とする段階で、専用MLIPや反応力場の投資が有利になりやすい。工程の飽和・時間依存が主題なら、長いMDより表面MKMを先に構築する。溝の均一性はその後に輸送と結合する。

### 用途例 金属酸化物の新規除去ガスを探す


#### 単一ガスから反応の組合せへ

金属酸化物の熱ALEでは、改質した表面層を配位子交換や付加体形成で揮発化させる設計が有力な探索軸となる。候補は「ガス分子1種類」だけでなく、改質剤、除去剤、供給順、温度の組合せとして管理する。

2026年の会議要旨には、ZrO₂のH₂O/SOCl₂系や、N複素環式カルベンを用いる配位子付加型の熱ALEが報告されている。新規ガス探索を、改質反応と金属の揮発化反応の組合せとして考える最近の候補例である。査読済み機構の確定とは分けて扱う。[[R16](#r16)]

2025年のAl₂O₃/HF/TMA研究は、非晶質表面、フッ化層、除去生成物を含む第一原理解析の具体例である。分子状TMAの反応熱だけを比べるのではなく、改質された固体表面と揮発性錯体の両方を計算する設計が参考になる。[[R05](#r05)]

| 比較対象 | 必要な入力 | 計算して判断すること |
| --- | --- | --- |
| 改質の深さと飽和 | 表面相、終端、改質剤の化学ポテンシャル | 表面反応で止まるか、内部まで進行するか |
| 除去剤の配位子 | 吸着配置、単量体・会合体、競合生成物 | 金属を含む脱離物が生成するか、表面結合が切れるか |
| 選択性 | 対象膜、下地、マスクの同条件モデル | 対象だけが除去される温度・分圧域があるか |
| 工程の自己制御 | 反応後の終端と次分子の反応経路 | 追加曝露で停止するか、連続エッチになるか |
| 残渣と再堆積 | 配位子分解、C・F・Clを含む表面状態 | 除去と堆積が競合しないか、生成物が再吸着しないか |

#### 推奨する計算の順番

分子DFTで複数の脱離錯体と気相安定性を比較する。次に周期表面DFTで吸着と金属原子を抜く経路を比較し、有望な組合せに限って自由エネルギーと速度を計算する。大きな配位子の配置探索はxTBや検証済みMLモデルで前処理できるが、最終障壁と反応エネルギーは統一したDFT条件で再評価する。

公開された一般材料モデルに対象元素が含まれていても、金属フッ化物と有機配位子の混合環境が学習されているとは限らない。新配位子を広く変える探索では分子計算を残し、特定の反応系列を大量に計算する段階で専用MLIPへ移る。

#### 実験と結ぶ成果物

候補ごとに、想定脱離生成物、律速候補、成立温度域、停止機構、保護膜への反応、未評価経路を一枚の評価票へ記録する。反応が熱力学的に有利という結果だけで、実用エッチングガスと判定しない。

GRRMやNEBの探索効率改善は、最終的にDFTでTSと生成物を検証できるため、比較的明確に価値を判定できる。一方、新しい加速時間法は、反応の発見に使えることと速度が正しく復元できることを別々に評価する。まず既知の小さなエッチング関連反応で通常計算や実験と比較する。

EATR系のような方法も、得られた速度を反応器の長時間計算に使うには、状態定義、バイアスによる遷移状態への影響、独立な待ち時間統計を検証する必要がある。一般分子系での改善率を、そのまま表面反応の加速率として採算計算に入れない。

#### 新規ガス探索における実務的な優先順位

第一に、反応前後の表面状態と生成物を網羅する。第二に、支配的な障壁とその不確かさを絞る。第三に、被覆・時間・輸送の効果を加える。高度な加速アルゴリズムは、これらの課題が特定できた後に導入する。未知ガスの比較では、速度のない大規模な構造動画より、反応ネットワークと成立条件の方が判断に直結しやすい。

### 気相反応と追加の物理を計算する


#### 非ML計算による到達化学種の評価

新規ガスを導入したとき、表面へ届く前の分解や会合が重要なら、表面計算とは別に気相反応ネットワークを作る。分子DFTで反応物・中間体・TSを探索し、支配的な経路を高精度波動関数法で再評価する。CCSD(T)などは少数の分子反応の参照計算に有用だが、DFTより高価で、大きな周期表面の通常MDの計算器には向かない。

| 方法 | 入力と出力 | 使う条件と限界 |
| --- | --- | --- |
| 高精度分子電子状態 | 分子、電荷・スピン、基底 → エネルギーと障壁 | 候補順位に影響するDFT誤差の確認。単一参照近似が悪い場合は多参照法を検討 |
| RRKMとmaster equation | 井戸・障壁・振動、衝突エネルギー移動、T、P → 圧力依存の速度・分岐 | 化学活性化した会合体、解離、第三体安定化。衝突パラメータが必要 |
| 気相反応器MKM | 素反応、流入組成、温度、圧力、滞留時間 → 到達種候補 | Cantera等で0次元から開始。壁損失・輸送は必要に応じ追加 |
| 量子核効果 | ポテンシャル、H移動経路、温度 → トンネル補正・量子自由エネルギー | 低温・軽い原子で影響を検討。経路積分のサンプリング時間を反応の実時間としない |
| 非断熱・励起状態 | 電子状態、結合、遷移条件 → 電子状態間の遷移と反応 | 励起種や荷電粒子で必要な場合。通常の基底状態MLIPだけでは表せない |

#### 直接関連する原著の使い方

NF₃とリモート放電NH₃/N₂の研究では、分子DFT、高精度単一点計算、統計速度論、master equation、Canteraによる気相モデルを組み合わせている。新規ガスが上流で変換される場合の手順として参考になる。[[R02](#r02)] 表面への入力としては、装置条件に対応した到達種のフラックスと分布を渡す。

#### 実装と費用の位置付け

ORCA等の分子電子状態計算器と、圧力依存速度の専用計算、Cantera等の反応器モデルを分担させる。Cantera単独で未知反応の障壁やRRKMネットワークを生成できるわけではない。追加の量子核・非断熱計算は、本レポートの標準構成への必須追加ではなく、実験の温度依存や電子状態に基づき必要性を判断する。

### 機械学習を役割で分ける


機械学習を使う目的は少なくとも四つに分かれる。原子の力を近似すること、次に計算する構造を選ぶこと、プロセス性能を近似すること、次の実験条件を選ぶことである。これらは入力も検証方法も異なる。

| 用途 | 入力と出力 | 事前学習と主要な制約 |
| --- | --- | --- |
| MLIPによるMD・経路計算 | 構造、元素、必要に応じ電荷・スピン → エネルギーと力 | 一般事前学習または専用学習。反応領域の学習範囲が重要 |
| 能動学習 | 候補構造とモデル不確かさ → 次のDFT計算点 | 汎用重みは必須でない。評価の偏りと探索漏れに注意 |
| 物性・速度の代理モデル | 分子記述子、表面、T、P、条件 → 障壁・速度・選択比等 | 通常は目的データで学習。未知化学への外挿は別検証 |
| Bayesian optimization | 過去実験・計算と目的・制約 → 次の候補条件 | 用途に合う観測データが必要。反応機構は自動的には説明しない |
| 学習CV・状態分類 | 軌跡や局所構造 → 進行度・状態ラベル | 探索補助。物理的反応の定義と速度検証は残る |

#### 事前学習済みという言葉を四段階に分ける

汎用事前学習は、材料や分子の幅広いデータを学んだ状態である。用途特化の既存重みは、特定のガス・基板・条件を学んだモデルである。追加学習はそのどちらかを目的系のDFTデータで更新する。新規学習は、重みを初期化して目的系からモデルを作る。採用票ではこの四者を明示し、「学習済み」の一語で済ませない。

#### 化学計算との関係

MLIPを使ってもMDの時間積分、NEB、自由エネルギー計算の原理は同じである。MLIPはその中のエネルギー・力計算を置き換える。MLによる高速化後も、表面モデル、反応経路、十分な統計、実時間への変換は必要である。

新規ガス探索に対して、汎用事前学習モデルの初期構造最適化を試す価値はある。ただし候補ガスの採否を決める障壁・脱離・生成物に使う前に、独立した量子化学データで検証する。検証に不合格でも、構造提案器として使い、DFTで再最適化する用途を残せる。

#### 化学モデルのどの部分を学習に置き換えるか

概念図09の教師データは、入力構造とそのDFTラベルの対である。推論時には新しい構造からエネルギーと力を出す。プロセスのエッチ速度を直接学習する代理モデルとは、入力空間も出力も異なる。


<a id="fig-c09"></a>

![概念図09：MLIPの教師データと推論](figures/C09.png)

**概念図09　MLIPの教師データと推論。** 同じ構造を電子状態計算と機械学習の入力処理へ渡し、参照エネルギー・力との誤差で学習する。推論時に各ステップでDFTを必ず実行する構成ではない。


MLIP開発の成果物は、モデル重みだけでは完結しない。参照DFT条件、適用する元素・電荷・表面状態、独立検証結果、MDとの接続、外挿を検出したときの扱いを一組にする。一方、ガス候補や工程条件を選ぶ代理モデルの成果物は、実験条件と観測値のデータ集合、予測の不確かさ、次の候補選択則である。[代理モデルと実験条件の最適化](#section-21)で別に扱う。

#### エネルギーを混ぜる落とし穴

気体を分子用の高精度学習head、固体を別のPBE系headで計算し、その値を単純に引いて反応エネルギーにしない。汎関数、原子基準、補正、モデルのタスク定義が異なるためである。反応前後を同じ計算条件で扱うか、明示的な校正と検証を行う。

#### PFPの最近の更新

2026年7月のPFP v9公式発表は、r²SCANモードの96元素対応と、表面・吸着、配位錯体などへの拡張を案内している。これはベンダーによる製品情報であり、任意のエッチングTSや絶対速度の精度保証ではない。対象反応の比較試験を行ったうえで契約価値を判断する。[[S23](#s23)]

### 専用MLIPを作る場合の選択


#### 目的用途に合わせた学習

ガス、基板、生成物、反応途中を同じ参照計算で学習する専用MLIPは、非晶質表面、被覆変化、多数の衝突の統計を繰り返す用途に向く。専用モデルを開発する場合も、DFTのモデル誤差は残る。学習器の誤差と参照DFTの誤差を分けて評価する。

| 候補 | 得意な構成 | 事前学習と実装負担 |
| --- | --- | --- |
| MACE | 等変表現によるエネルギー・力。追加学習と専用学習 | 一般重みを利用できるがライセンス別。PyTorch系。ASE接続から開始 |
| NequIP・Allegro | 等変モデル。Allegroは局所性を活かした並列MD | 専用学習の基盤。一般重みの存在と対象適合は別。LAMMPS連携版を揃える |
| DeepMD kit | Deep Potentialと能動学習、LAMMPS連携 | 枠組みだけではエッチ用重みを得ない。対応backendと導入手順を固定 |
| NEPとGPUMD | コンパクトな原子環境記述と高速GPU MD | 通常は対象データで学習。GPU実行を重視する候補 |
| ACE・GAP系 | 系統的な基底やカーネルによる局所エネルギー学習 | 少数元素の専用モデル候補。実装とモデルごとの利用条件を確認 |

#### データ集合に必要なもの

清浄面・改質面・欠陥・複数被覆、単離ガス、ラジカル、主要生成物、吸着配置、結合伸長、NEB周辺、短距離接近、温度で歪んだ構造を含める。入射を扱う場合は、そのエネルギー域の反発と表面損傷も必要となる。安定構造だけの学習では、障壁や反応経路を支えられない。

#### 能動学習の運用

初期DFT集合で複数モデルを学習し、短いMD・経路探索・被覆探索を行う。モデル間差や外挿指標で候補を選び、DFTでラベル付けして再学習する。同時に、低い不確かさで共通して誤る場合を検出するため、無作為点と重要反応の固定テスト集合を残す。モデルの正しさは独立したDFTテストで確認する。

コストの中心は学習GPUだけでなく、DFTラベル、探索、失敗した構造の診断、モデル更新の管理である。大量の繰返し計算が予定されていない場合は、少数のDFT経路計算で目的を満たす方が合理的なこともある。[[R08](#r08),[R12](#r12),[S21](#s21),[S24](#s24)–[S27](#s27)]

構成図B01では、データ集合の作成・分割を学習より先に行う。反応系列や表面モデルをまたいだ独立評価を残し、学習後のMD試験で物理的安定性を確認する。

### 事前学習と追加学習の採用基準


| 判定 | 確認する証拠 | 推奨する選択 |
| --- | --- | --- |
| 対象に近い公開重みがある | 同じガス・基板・被覆・温度域、学習データ、テスト条件、重み入手性 | 独立テストを通れば再利用。文献の存在だけでは採用しない |
| 一般事前学習の対応は広い | 目的結合、表面、電荷・スピン、生成物、TSへの誤差 | 構造前処理から試す。速度に使う前に反応特化の検証 |
| 近いが重要な領域が欠ける | 小規模DFTテストで局所的な誤り、学習・改変権限がある | 追加学習。元領域の忘却も同時に評価 |
| 大きく領域が異なる | 未対応元素・電荷、別の電子状態、重大な反応経路誤り | 専用学習または量子計算を継続。汎用重みを無理に使わない |
| 契約が学習・持出しを制約 | 企業利用、派生重み、社外データ、再配布、利用期間 | 権利と運用が合う実装へ変更、または契約条件を確定 |

#### 合格判定の具体化

初期の検証集合は、単離ガスと生成物、複数の表面終端、低・高被覆、主要な反応前後と経路、実温度の短いMDから構成する。必要数を一律に決めず、候補の順位や速度の感度が安定するまで増やす。反応物から生成物へのエネルギー差とTSの相対エネルギーを、総エネルギーRMSEとは別に評価する。

データ分割は、軌跡、反応系列、表面構造、ガス候補で分ける。同じMD軌跡の隣り合うフレームを無作為に訓練・テストへ分けるだけでは、新しい反応への性能を過大評価しやすい。未知ガスへの利用を主張するなら、ガス系列を丸ごと外した検証を設ける。

MDでは原子の異常接近、エネルギードリフト、非物理的な分解、誤った生成物安定化を調べる。短い軌跡の安定性だけで長時間の反応統計を承認しない。少数でも独立したDFT経路と実験の速度・組成に照合する。

#### 採用記録に残すもの

重みの版とハッシュ、参照汎関数、原子エネルギー基準、対応する電荷・スピン、学習・検証範囲、利用権、使用を止める外挿条件を記録する。ゼロショット、追加学習、専用学習を同一条件で比較し、必要精度を満たす総費用が最小の構成を選ぶ。

#### 事前学習の採用は重みの入口と目的データを分けて判断する

概念図10と構成図B03の三経路は、ゼロショット、追加学習、新規学習である。ゼロショットでも目的系の評価データは必要であり、追加学習しないことと検証しないことを同一視しない。

**概念図10　事前学習・追加学習・新規学習。** 既存重みをそのまま評価する経路、既存重みを目的データで更新する経路、目的データで新たに学習する経路を比較する。

**構成図B03　事前学習利用の三経路と採用判定。** 既存重みと目的DFTデータを独立の入力として管理し、各経路の結果を共通の反応・MD評価へ渡す。目的DFTラベルを作らずに転用の妥当性を判断する構成ではない。


目的用途に特化した公開重みを採用するには、同じガス名だけでなく、表面相・終端・荷電状態・温度・入射エネルギー・生成物を照合する。一般材料の事前学習モデルは、初期構造の提案には使えても、脱離障壁や残渣形成の順位付けには追加検証を要する。一般モデルからの追加学習と新規学習のどちらが有利かは、必要なDFT点数と最終精度、運用費用を同じ条件で比較して決める。

採用記録には「目的系で事前学習済み」「一般事前学習から転用」「目的系で追加学習」「目的系で新規学習」の区分を必須項目として設ける。モデル名だけでは再現できないため、重み版・計算タスク・エネルギー基準も併記する。[一般事前学習モデルの候補](#section-18)の一般モデル一覧は、この判定の候補リストである。

### 代理モデルと実験条件の最適化


#### ガス候補を順位付けする代理モデル

入力はガスの構造・記述子、対象材料、表面終端、共反応物、温度・圧力などで、出力は反応障壁、生成物形成、エッチ速度、選択比などである。Gaussian process、木モデル、GNNなどが候補となる。これらは原子の力を出すMLIPとは別のモデルである。

学習には、目的条件に対応するDFTまたは実験のラベルが必要となる。分子物性の事前学習表現を使っても、エッチ速度が事前学習されていることにはならない。同じガスでも装置、表面、曝露履歴によって結果が変わるため、欠測したプロセス情報を単一のガス記述子で代用しない。

#### Bayesian optimization

少数の高価な実験を逐次選ぶ目的に適する。現在の性能と不確かさをモデル化し、獲得関数で次の候補を選ぶ。温度、混合比、パルス時間、候補分子の離散選択を扱い、速度、選択比、残渣などの多目的・制約付き探索にする。BoTorchはPyTorchベースの実装候補である。[[S29](#s29)]

| 用途 | 事前学習の要否 | メリットとデメリット |
| --- | --- | --- |
| 既存ガスの条件最適化 | 専用の実験履歴で学習。一般目的の観測データから開始できる | 少数実験を選びやすい。装置ドリフトとノイズの扱いが必要 |
| 新規ガスの探索 | 分子表現の転用は可能。目的ラベルは別途必要 | 候補数を減らせる。未知化学領域では外挿の根拠が弱い |
| 多忠実度最適化 | 粗い計算、DFT、実験の関係を学習 | 安価な計算を活用。低精度と高精度の順位が合わないと失敗 |
| 速度論の代理化 | 既存MKMや形状計算の出力で学習 | 多数条件を高速走査。基礎モデルの誤差を継承する |

#### 実用の評価方法

ランダム探索や単純な実験計画と、同じ実験予算で比較する。探索範囲外を予測できると仮定せず、候補の信頼区間、棄却条件、確認実験を残す。学習・推論は原子計算より軽いことが多いが、費用の大半がラベル取得であることは変わらない。

反応機構の説明が目的なら、相関を学ぶ代理モデルだけで結論を出さない。選ばれた候補について、DFTの反応経路または表面・生成物測定を追加し、性能が変わる理由を確認する。

### 必要な空間と時間を分ける


原子反応を追跡する領域と、装置・パターン全体を計算する領域を分ける。下表は計画用の代表的な対象範囲であり、各ソフトの性能上限ではない。原子数、電子状態、ハードウェア、必要な統計精度で実行可能範囲は大きく変わる。

| 階層 | 主な対象 | 計算から得る情報 |
| --- | --- | --- |
| 分子と局所反応 | 分子、吸着サイト、数層の表面 | 生成物、反応経路、吸着自由エネルギー、障壁 |
| 原子集団 | nm領域の表面、改質層、衝突 | 欠陥、被覆、生成物分布、反応確率、局所構造 |
| 表面速度論 | 長時間の被覆率と組成変化 | 秒単位の速度、誘導時間、飽和、EPC |
| フィーチャー | nm〜µmの溝・孔・側壁 | 局所フラックス、深さ方向の均一性、形状変化 |
| 装置 | 反応器とウエハ近傍 | 到達化学種、分圧、滞留時間、供給均一性 |

#### 全原子MDで大空間と長時間を同時に扱う難しさ

原子密度を仮に50 atoms/nm³とすると、10 nm立方体は約5万原子、100 nm立方体は約5千万原子、1 µm立方体は約500億原子になる。1 µm角の表面を厚さ10 nmだけ切り出しても約5億原子である。表面反応に重要な局所領域だけを原子で表す理由は、この体積増大にある。

時間刻みを0.5 fsと仮定すると、1 µsには20億ステップが必要である。また、単一の反応について試行頻度10¹³ s⁻¹、障壁1.0 eV、400 Kを仮定したArrhenius式では、平均待ち時間は約0.4 sとなる。どちらも説明用の計算であり、特定のエッチング反応の実測値ではない。

#### 目的のスケールに必要な接続

DFT・MDから局所反応の速度または確率を抽出し、表面速度論へ渡す。表面速度論は、輸送計算が与える局所フラックスと温度を受け取り、除去速度、消費フラックス、生成物放出量を返す。level setなどはその除去速度から形状を更新する。これにより、反応機構の説明と実用寸法の予測を同一のモデル体系にできる。

空間拡大と時間拡大を別々に見積もる。GPU化、並列化、MLIPは1ステップを速くするが、低頻度反応の待ち時間そのものを消さない。加速MDや速度論モデルには、別の仮定と検証が必要である。

#### 全体アーキテクチャと責任分界

構成図A01は、原子反応の計算とプロセス計算の間で渡す量を示す。電子状態計算のエネルギーを直接形状ソルバーへ入れるのではなく、熱化学補正、反応速度、表面での物質収支を順に構成する。各段階に入力の適用温度・被覆範囲と不確かさを添える。

![構成図A01：全体構成とスケール間の受け渡し](figures/A01.png)

**構成図A01　全体構成とスケール間の受け渡し。** 左から局所反応、表面速度論、輸送、形状を読む。矢印はモデル間の情報交換であり、全ソフトを一体化した既製製品を示すものではない。色分布と構造は模式例である。

### 計算に必要な入力と成果物


「ガス名と基板材料」だけでは、機構や速度を一意に計算できない。特に表面終端、微量水分、共反応物、改質層の履歴は、候補ガスの優劣を反転させ得る。次の情報を計算仕様書として最初に固定する。

| 入力群 | 最低限の内容 | 不足した場合の扱い |
| --- | --- | --- |
| 材料と表面 | 組成、相、結晶面または非晶質、膜密度、OH・H・F終端、欠陥 | 複数の表面モデルを用意し、結果の幅を報告 |
| ガスと供給 | 分子・ラジカル・イオンの区別、混合比、分圧、供給順、パルス・パージ | 導入ガスと到達種を区別し、未測定量を感度解析 |
| 熱・エネルギー | 基板温度、ガス温度、入射角・エネルギー分布、電荷状態 | 熱反応と高エネルギー衝突を別条件として計算 |
| 幾何と履歴 | 形状、深さ、幅、側壁、前処理、改質層、サイクル番号 | 平面で校正し、別形状で予測を検証 |
| 判定指標 | 速度、選択比、残渣、粗さ、損傷、均一性、EPC | 優先順位と許容範囲を数値で定義 |

#### 階層ごとの出力を混ぜない

量子化学の出力は構造、エネルギー、力、振動、電荷密度、反応障壁である。MDの出力は軌跡とその統計である。いずれも、そのまま装置条件でのnm/minを意味しない。温度・分圧依存の速度定数、反応確率、サイト密度へ変換して初めて、プロセス速度に接続できる。

保存する成果物は、候補ガス一覧、表面構造集合、反応ネットワーク、各反応の根拠、速度式、適用温度・被覆率範囲、生成物分布、モデル誤差、検証条件である。候補が不適合だった理由も残す。反応しなかった計算と、計算範囲内では観測されなかった計算を区別する。

#### リモートプラズマの場合

供給したNF₃や添加ガスが、そのまま表面に到達するとは限らない。分解、気相反応、壁損失、再結合を含めて到達種を定める。NF₃/NH₃/N₂系の原著は気相反応経路とHF形成を扱っており、上流の化学が表面入力を左右する具体例となる。ただし、その気相モデルだけで表面エッチング機構まで決まるわけではない。[[R02](#r02)]

### 計算費用を同じ基準で見積もる


以下は相対的な計画目安であり、測定された実行時間ではない。ソフトの速度比較は、原子数、系、精度、時間刻み、ハードウェアを揃えた自社ベンチマークで行う。

| 区分 | 初期費用 | 反復時の主な費用 |
| --- | --- | --- |
| 分子・表面DFTとTS | 構造、収束、経路の設計 | 力評価数、SCF収束、NEB像、汎関数。中〜非常に高 |
| AIMD | 電子状態と表面の準備 | 全ステップで電子状態計算。非常に高 |
| DFTB・反応力場MD | 適合するパラメータ検証。新規開発なら高 | 原子数×ステップ×軌跡数。低〜中だが統計で増大 |
| 専用MLIP | DFTラベル・学習・検証。高 | GPU推論、近傍通信、軌跡数。DFTより軽いことが多い |
| MKM・反応拡散 | ネットワークとパラメータ同定 | 反応数、剛性、空間格子、感度解析。低〜中 |
| kMC・輸送・形状 | 反応則と幾何、境界の実装 | イベント・粒子・格子・サイクル数。中〜高 |
| 代理モデル・BO | 目的ラベルと評価設計 | 学習・推論は比較的軽い。実験・DFT取得が支配的 |

#### 再現できる見積もりの式

DFTラベルの資源量は、構造数×1構造の平均時間×割当コア数で概算する。MDは、目標物理時間/時間刻み×1ステップ時間×独立軌跡数で求める。料金はコア時またはGPU時に契約単価を掛ける。待ち行列、再実行、保存、ライセンス、担当者の開発時間を別項目にする。

仮にDFTラベル1構造が64コアで30分、必要数が2,000なら64,000 core-hoursである。10ノードで理想的に分散すれば100時間だが、実際は不均一なSCFと待ち時間で変わる。仮にMDの1ステップが1 GPUで5 ms、0.5 fs刻みなら、1 nsは約2.8 GPU-hours、1 µsは約2,778 GPU-hoursとなる。これらは仮定から算出した例で、特定ソフトの性能値ではない。

#### 追加学習の採算

学習前の計算費用をC₀、学習後をC₁、データ作成・開発費をCtrainとすると、同等精度を仮定した損益分岐の反復回数は概ねCtrain/(C₀−C₁)である。未知化学への拡張ごとに再学習費が発生する場合、その分も入れる。高速化率だけでML採用を決めない。

### 具体的な実装とデータの受け渡し


#### 最小構成から始める

非MLの初期構成は、ASEで構造・計算ジョブを管理し、CP2KまたはQuantum ESPRESSO等でDFTとNEBを実行し、表面MKMをCantera等に渡す。形状が必要になった段階でViennaPSを追加する。反応統計が不足した場合にのみ、LAMMPSの反応力場または専用MLIPを追加する。これは選択例であり、既存のVASPや商用環境があれば置き換えられる。

| 受け渡す記録 | 必須項目 | 利用先 |
| --- | --- | --- |
| 構造 | 元素、座標、セル、周期境界、電荷・スピン、終端、生成元、単位 | DFT、力場、MLIP、再現計算 |
| 量子ラベル | エネルギー、力、応力、計算設定、収束状態、参照エネルギー | MLIP学習、反応エネルギー |
| 素反応 | 反応物・生成物、サイト、TS、ΔG‡(T)、逆反応、適用被覆範囲 | MKMまたはkMC |
| 入射イベント | 種、E、角度、温度、表面状態、成功数、試行数、生成物 | 反応確率と輸送境界 |
| 表面則 | 反応・付着・脱離・拡散、表面状態の更新、体積換算、誤差 | 形状・輸送モデル |

#### 入出力の整合で最も起きやすい失敗

eVとJ/mol、barとPa、面積当たりフラックスとサイト当たり速度を混ぜない。反応式の元素・電荷・サイト収支を自動検査する。MDから得た「入射1個当たりの除去原子数」を、表面被覆と入射種の条件を落として定数にしない。

表面の法線速度は、正味の除去原子または化学式単位のフラックスと原子・分子体積から計算する。改質による体積増加、密度変化、生成物再堆積がある場合は、単純な除去量換算に追加項が必要となる。

#### ソフト接続の確認順

まず1構造のエネルギーと力を計算し、同じ構造の外部インターフェース出力と一致させる。次に短いMD、1本の経路、1種類の表面速度式、平面の除去量を確認してから形状へ進む。最初から全階層を接続すると、単位・モデル・連携のどこに誤りがあるか切り分けにくい。

#### 図の入出力を実装するための共通データ仕様

構成図A03・B01・B02の構造入力と、A02・A07の反応入力は別のデータ型として定義する。以下は推奨する内部仕様の例であり、各ソフトのAPI名を規定するものではない。外部ソフトへの入出力で単位を変換し、内部では一貫した単位を保持する。

| データ | 形状・単位の例 | 必須の付帯情報 |
| --- | --- | --- |
| 原子種・座標 | Z[N]、R[N,3]、Å | 原子ID、電荷・スピン、構造ID、生成経路 |
| セルと境界 | cell[3,3]、Å、pbc[3] | 真空層、固定原子、表面法線、座標規約 |
| 教師ラベル | E：スカラー eV、F[N,3]：eV/Å | 計算器・汎関数・擬ポテンシャル・収束・原子参照 |
| 応力 | 3×3テンソルまたは定義済み6成分 | 単位、符号、成分順。スラブの真空体積による規格化を明示 |
| 反応経路 | 構造ID列、TS ID、ΔG‡(T) | 反応式、原子対応、標準状態、検証済み接続先 |
| 速度則 | k(T,P,θ)または定義したパラメータ | 反応次数、単位、サイト基準、逆反応、適用範囲 |
| 入射と除去 | 分子または化学式単位／m²／s | 種、角度・エネルギー、被覆、正味／総量の区別 |
| MLモデル | 重みファイルと固定識別子 | データ版、分割ID、参照計算、用途への学習区分 |
| プロセス観測 | 条件ベクトルと目的量・不確かさ | 材料履歴、装置、単位、反復、欠測・検出限界 |

Nは構造ごとに異なり得る。学習バッチには構造ごとの境界を保持し、異なる構造の原子を一つの物理系として接続しない。データの採用状態は「計算失敗」「収束済み」「検証済み」などを分け、SCF未収束や不正な原子配置を通常の教師データに混ぜない。

構造の初期交換にはASEで読み書きできる形式、反応ネットワークには明示的なIDを持つ表・JSON等、速度論には実装が受け付ける機構形式を用いる。形式を統一するだけでなく、エネルギー基準とサイト密度が同じであることを確認する。[[S06](#s06),[S17](#s17)]

### 実験と照合して予測範囲を決める


学習やパラメータ調整に使った条件と、最終評価に使う条件を分ける。平面のエッチ速度に合わせたモデルが、溝や別の温度で正しいとは限らない。複数の観測量で、同じ速度を与える異なる機構を区別する。

| 検証対象 | 対応する観測例 | 判定の意味 |
| --- | --- | --- |
| 除去と飽和 | 膜厚、QCM、EPC、曝露時間依存 | 表面反応停止、遅い脱離、供給不足を区別 |
| 表面中間体 | XPS、FTIRなどの組成・結合状態 | 反応ネットワークと終端の妥当性を確認 |
| 揮発性生成物 | 排気の質量分析、ガス分析 | 基板原子が何として除去されるかを確認 |
| 温度依存 | 速度と生成物の温度変化 | 律速候補を比較。見掛け活性化エネルギーを単一障壁と同一視しない |
| 選択性と残渣 | 対象膜と保護膜の同条件比較、表面・深さ分析 | 候補ガスの採否に直結。低速度側の検出限界も記録 |
| 形状と粗さ | 断面観察、深さ方向の膜厚、AFM | 輸送、局所反応、相・面方位のばらつきを評価 |

#### 不確かさを三つに分ける

第一は参照物理の不確かさで、DFT汎関数、表面相、欠陥、反応ネットワーク漏れを含む。第二は数値・統計誤差で、セルサイズ、時間刻み、サンプル数、収束などである。第三はモデル移植の誤差で、DFTからMLIP、原子からMKM、平面から形状への近似を含む。各段階で誤差を別々に記録し、最終出力へ伝播する。

#### ガス探索の比較指標

エッチ速度最大化だけでなく、選択比、除去当たりの残渣、粗さ、供給と排気の成立性、サイクル時間を同時に比較する。選択比は分母が検出限界以下のとき、有限の確定値として扱わず下限値を報告する。膜厚変化がゼロに近い場合も、化学改質が起きていないとは限らない。

採用判断を左右する未測定量があれば、モデルをさらに複雑にする前に、その量を区別できる実験を優先する。例えば生成物分析は、同じ除去速度を与える直接揮発化と塩形成後脱離の区別に役立つ。

#### 現時点での採用候補

新規ガス化学を重視する基本案は、DFT＋NEBまたは鞍点探索＋必要に応じAFIR/AIMDである。長時間速度にはMKM、実用形状には輸送とlevel setを追加する。kMCは局所相関や島形成が結果に効くと分かった場合に採用する。

MLの基本案は、最初に一般事前学習モデルを小さな検証集合で評価し、構造前処理や探索補助として使うことである。大量MDが必要となり、目的系のDFTデータが揃えば、追加学習と専用学習を比較する。目的の表面反応に適合する公開重みが見つかれば、それも同じ基準で比較する。

#### 開始前に確定すべき五つの情報

対象材料と保護材料、候補ガスと共反応物、熱反応か中性ラジカルかイオン支援か、欲しい出力と寸法・時間、利用可能な計算資源とライセンス予算。この五点が決まれば、最初のDFT検証集合とソフト構成を具体的に選べる。

判断の中心は「どの情報がまだ不足しているか」である。反応機構が不足していれば量子計算、原子統計が不足していれば反応MD、時間・空間への接続が不足していれば速度論と輸送、反復計算の費用が支配的なら機械学習を追加する。

#### 用途別に選ぶ初期開発パッケージ

以下は本レポートの手法選定を開発単位へまとめたものである。採用理由は必要な情報を取得できるかに置き、計算規模だけで順位を付けない。ライセンスと導入条件の根拠は[化学計算ソフトと導入の比較](#section-25)、[探索と速度論と形状の実装比較](#section-26)、[機械学習実装と利用条件の比較](#section-27)を参照する。

| 開発課題 | 最小の構成 | 最初の成果物 | 拡張を判断する証拠 |
| --- | --- | --- | --- |
| 未知ガス・添加剤の候補比較 | ASE＋周期DFT、分子DFT、NEB／TS探索 | 対象膜と保護膜の除去サイクル、競合障壁、脱離生成物 | 生成物が未確定ならAFIR/AIMD、複数配置が順位を変えるなら構造探索を追加 |
| 非晶質面・被覆率によるばらつき | 複数表面のDFT検証＋適合する反応MD | サイト別反応確率と信頼区間、改質・残渣分布 | 必要な軌跡数がDFT費用を支配するなら専用MLIPを比較 |
| 曝露時間・温度・サイクルの設計 | Cantera等の表面MKM＋実験校正 | 被覆率、EPC、生成物、曝露・パージ応答 | 局所相関が観測を左右するならkMC、厚い層内輸送なら反応拡散を追加 |
| 溝・孔の均一性と形状 | 局所表面反応則＋ViennaPS等 | 深さ別フラックス・除去量と形状 | 気相衝突が無視できなければDSMC、装置供給が律速なら装置輸送へ接続 |
| 計算資産のある化学系の大量MD | 固定DFT基準＋MLIP学習＋ASE/LAMMPS等 | 反応検証済みモデル、推論速度、適用範囲 | 能動学習で未検証領域を追加。新規元素・荷電状態へ拡張する前に再評価 |
| 少数の高価な試験で工程を改善 | 実験データ整備＋GP/BoTorch | 制約を満たす次の試験条件と確認試験 | 新規化学系列を増やす場合はDFT・機構評価の枝を追加 |

#### 開発段階ごとの受入条件

| 段階 | 完了時に残す記録 | 進めない場合の対応 |
| --- | --- | --- |
| 計算仕様 | 材料・表面履歴・供給種・条件範囲・目標観測量 | 表面状態が不明なら複数仮説を設定し、測定で絞る |
| 電子状態の基準 | セル・基底・k点・SCFの収束、採用汎関数、気相と表面の参照 | 設定差が候補順位を変えるなら基準計算を精密化 |
| 反応ネットワーク | 原子・電荷・サイト収支、TS接続、主要な競合経路 | 未確認の生成物や障壁が支配する場合は探索へ戻る |
| 原子モデル | 反応別誤差、短距離安定性、独立表面・軌跡の試験 | 対象反応に外れる力場・MLIPは用途を限定または再学習 |
| 平面プロセス | 速度・飽和・組成・生成物の同時比較 | 単一速度だけが合う場合は機構とパラメータ識別を再検討 |
| 形状への展開 | 未校正の形状・温度・曝露での予測と誤差 | 平面則の移植、輸送、改質層のどこが不足か切り分ける |
| 継続運用 | 実行環境、ソフト・重み版、データ、費用、適用外条件 | 担当者以外が再実行できない構成は運用移管しない |

受入基準の数値は、目標とする速度・選択性の許容誤差から決める。[物理的な速度と長時間を得る](#section-10)の障壁感度を用い、参照DFTの不確かさより小さい誤差をMLIPだけに要求しても、最終精度は改善しない点を考慮する。モデルの合否、判断根拠、適用を認める条件を一枚の採用票に記録する。

#### 担当範囲と実装の着手順

化学計算担当は表面モデル・参照DFT・反応機構、速度論担当は反応式・標準状態・時間発展、輸送担当はフラックス・境界・形状、ML担当はデータ分割・学習・外挿、実験担当は膜履歴・観測・検出限界を担当範囲とする。小規模チームでは兼任できるが、各境界の入力と出力を明記する。

最初の実装は一つの候補ガスと一つの表面状態に限定し、「DFTの構造とエネルギー→一つの検証済み反応→平面の物質収支」を通す。次に保護膜と競合経路、被覆依存、パルス工程を追加する。大量軌跡、MLIP、溝形状は、それぞれの必要性が確認できた段階で独立に拡張する。各段階のデータを保存しておけば、計算器を変更しても反応機構とプロセスモデルの全てを作り直す必要はない。
